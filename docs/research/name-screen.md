# Name screen

Status: research, checked 2026-09-27. Written in ASD-STE100 (D-17).

The owner found an upcoming game with the name Emberline on Steam. The session then screened new names, and the owner picked Iron Absolution (D-39). This file records the method and the results.

## 1. Method

- The session queried the Steam store search and the itch.io search for each candidate. A result that holds the candidate as a substring is a hit.
- For each name that passed, the session did a web search for a game, a product, a band, or a book with that name.
- For the finalists, the session did a WHOIS query on the `.com`, `.gg`, and `.io` domains.
- This screen is not a trademark clearance. The session did not query a trademark database.

## 2. Results

| Name | Result |
|---|---|
| Emberline | Steam app 4750920, an upcoming game. Refused. |
| Condemnation | Two itch.io games with this title. It is close to Condemned, a first-person series on Steam. The `.com` domain is registered. Refused. |
| Iron Judgment | The title of a paid expansion of GWENT (2019). Refused. |
| Iron Verdict | Steam app 4988200, and a Magic: The Gathering card. Refused. |
| Iron Decree, Iron Mandate, Iron Reckoning | Each is a game on Steam. Refused. |
| Iron Absolution | No hit on Steam or itch.io. The web search found one production-music track of 2016. The `.com` domain is free. Picked (D-39). |
| Iron Sentence, Iron Warrant, Iron Tribunal | No hit on Steam or itch.io. Not picked. |
| Knife Weather, Hard Vespers, Spentfire | No hit on Steam, itch.io, or the web. Not picked. |
