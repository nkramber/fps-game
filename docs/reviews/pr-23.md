### P2-1: Accepts a CSV file marked incomplete

Status: fixed in `09ac790`.

Open at: `13bdbb1c6cd187e867b644be9afaf5c4ec95db2c`.

File: `IronAbsolution.Tools/FrameCapture/FrameTimeCsv.cs:83-92`.

Trigger: The closing metadata contains `[HasHeaderRowAtEnd],0`, with otherwise valid rows and settings.

Expected: The reader accepts only a completed profiler file (D-137, T-2).

Actual: The old reader checked only that the completion key exists.

Consequence: An incomplete profiler file could provide a passing value of M-3.

Evidence: Commit `09ac790` requires the value `1`. The new regression cases for `0` and an empty value fail with the source path, line, and value. `run.ps1 verify` passes with 598 tests.

Correction: Require the completion marker value `1` and report an invalid value with its context.

Regression check: `FrameTimeCsvTests.AMarkOfTheFinishedFileOtherThanOneFails` passes for both invalid values. The old reader accepts both values because it checks only for the key.

### P2-2: Does not require a valid view count

Status: fixed in `09ac790`.

Open at: `13bdbb1c6cd187e867b644be9afaf5c4ec95db2c`.

File: `IronAbsolution.Tools/FrameCapture/FrameCaptureRules.cs:203-226`.

Trigger: The metadata omits `IronAbsolution.ViewCount` or gives a value that is not a positive whole number.

Expected: Each passing capture reports the number of views it used (D-137, T-2).

Actual: The old rule passed when the key was absent and reported an unknown number of views.

Consequence: A capture with no valid view count could pass the settings check.

Evidence: Commit `09ac790` requires the key and a positive integer. The new regression cases reject an absent key and values `0`, `-3`, and `four`. The count remains data from the content script and gym test (D-134). `run.ps1 verify` passes with 598 tests.

Correction: Require a positive whole number, without duplicating the view-set count in C#.

Regression check: `FrameCaptureRulesTests.AnAbsentOrInvalidViewCountFailsTheSettings` passes for each invalid case. The old rule passes those cases when the key is absent and accepts arbitrary text when it is present.
