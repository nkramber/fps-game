Trigger: A Blueprint sets `Lifetime`, `Diameter`, or `HitMarkerSeconds` to positive infinity.

Expected: Each non-finite tuning value reports its actor path and value. The flash lifetime, flash size, and hit-marker duration stay finite (T-2, D-29, D-154).

Correction: Reject non-finite values before the positive range checks. Include the actor path and invalid values in each error.

Regression check: `IronAbsolution.Player.Weapon.Errors` must pass for infinite lifetime, diameter, and HUD duration, and must fail on the old checks. The author reports that the regression test failed on the old code and passed on the new code.
