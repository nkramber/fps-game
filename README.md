# FPS Game

An in-progress fast-paced, resource-limited first-person shooter prototype in Unreal Engine 5.

The initial milestone is one complete, replayable level built on a reusable foundation for future levels. See the coding-agent launch prompt in the project outputs for the research questions, first milestone, and acceptance criteria.

## Repository conventions

- Commit Unreal source assets, `.uproject`, `Config/`, `Content/`, `Source/`, and project plugins needed to build the game.
- Do not commit generated Unreal folders such as `Binaries/`, `DerivedDataCache/`, `Intermediate/`, or `Saved/`.
- Record the supported Unreal Engine version and exact setup/run steps here once the project is created.
- Keep generated and third-party assets traceable to their source, license, and import settings.
